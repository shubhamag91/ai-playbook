Prompt Engineering

Get Better Outputs from LLMs (Tested Techniques)

The 3 Golden Rules

1. Be Specific

Bad:

Write about AI

Good:

Explain transformers in 3 paragraphs for a CS student

2. Give Context

Bad:

Classify this

Good:

You're a UX reviewer. Rate this design for mobile.

3. Show Examples

Good:

"Like this (example). Now do this (task)."

5 Quick Wins

  • Add role: "You're a Python expert..."
  • Add constraints: "Keep it under 100 words"
  • Add format: "Return as JSON"
  • Think step-by-step: "Explain your reasoning"
  • Few examples: Show 2-3 input/output pairs

Prompt Template (Steal This!)

You are a [ROLE]. Your goal is to [GOAL]. Context: [BACKGROUND] Task: [WHAT TO DO] Constraints: [WHAT NOT TO DO] Format: [HOW TO ANSWER] Input: [USER INPUT]

Advanced Techniques

Chain-of-Thought: "Let's think step by step"

Few-Shot: Examples before the real question

Role-Play: "You are..."

Decomposition: Break into smaller tasks

Iteration: Ask follow-ups ("refine this" / "shorter")

Common Mistakes

✗ Being rude

→ Be polite

✗ Vague

→ Be specific

✗ Too long

→ Keep focused

✗ Contradictions

→ Clear priorities

Fix: Rerun with better prompt.

Testing Your Prompt

  • Consistency: Run 3x. Are results similar?
  • Accuracy: Test on 5 known examples
  • Edge cases: Try unusual inputs
  • Cost: Count tokens (cheaper = fewer tokens)
