## 🟢 Beginner Level

Essential concepts everyone should understand.

<CardGrid>
  <Card title="Artificial Intelligence (AI)" icon="star">
    Technology that mimics human-like thinking. Includes chatbots, recommendation systems, image generators — anything that "thinks" without explicit programming.
  </Card>
  <Card title="Large Language Model (LLM)" icon="book">
    An AI trained on massive amounts of text to understand and generate language. Powers ChatGPT, Claude, Gemini and most AI assistants you use daily.
  </Card>
  <Card title="Token" icon="seti:json">
    The basic unit LLMs process — roughly ¾ of a word. Example: 'ChatGPT' = 2 tokens, 'hello' = 1 token. Cost is measured in tokens.
  </Card>
  <Card title="Context Window" icon="seti:window">
    How much text an LLM can 'see' at once. Think of it as short-term memory. Claude 4.7: 400K tokens. Gemini 3.1 Pro: 1M tokens (entire books).
  </Card>
  <Card title="Prompt" icon="pencil">
    The question or instruction you give an AI. Good prompts = better answers. 'What is AI?' is a prompt. So is 'Write a poem about cats.'
  </Card>
  <Card title="Hallucination" icon="warning">
    When an LLM confidently generates false information. It's not lying — it's pattern-matching that produces plausible but incorrect text.
  </Card>
  <Card title="Multimodal" icon="seti:image">
    An AI that understands multiple types of input: text, images, audio, video all in one model (e.g., GPT-4o, Claude, Gemini).
  </Card>
  <Card title="Temperature" icon="thermometer">
    A dial controlling how 'creative' or 'random' an AI is. 0 = always same answer, 1 = balanced (default), 2 = very random. Lower = more predictable.
  </Card>
</CardGrid>

## 🟡 Intermediate Level

For people building with AI or working deeper.

<CardGrid>
  <Card title="Transformer" icon="seti:cpu">
    The neural network architecture (2017) that powers virtually all modern LLMs. It has 'attention' — the ability to understand which words matter most in a sentence.
  </Card>
  <Card title="Embedding" icon="seti:database">
    A numerical vector representing text, images or data as points in space. Similar meanings = similar vectors. Powers semantic search and RAG.
  </Card>
  <Card title="Fine-tuning" icon="pencil">
    Specialized retraining of a pretrained model on your own dataset to make it better at a specific task or domain.
  </Card>
  <Card title="RAG (Retrieval-Augmented Generation)" icon="book">
    A technique that retrieves relevant documents from a knowledge base BEFORE generating answers. Dramatically reduces hallucinations.
  </Card>
  <Card title="Prompt Engineering" icon="wrench">
    The art of crafting effective inputs to get better outputs — includes chain-of-thought, few-shot examples, role-playing, and constraints.
  </Card>
  <Card title="Chain-of-Thought" icon="git-branch">
    Prompting technique asking the model to 'think step by step.' Improves accuracy on math, reasoning and complex problems by 20-40%.
  </Card>
  <Card title="Few-Shot Prompting" icon="list">
    Including 2–5 examples of the desired output format in your prompt. The model learns the pattern and copies the style.
  </Card>
  <Card title="System Prompt" icon="settings">
    Instructions given to an AI at the start to set its persona, knowledge base, tone and constraints. 'You are a helpful assistant trained in law.'
  </Card>
  <Card title="Vector Database" icon="database">
    Specialized database optimized for storing embeddings and searching by semantic similarity (Pinecone, Chroma, Weaviate, Milvus).
  </Card>
  <Card title="Semantic Search" icon="magnifier">
    Finding conceptually similar content instead of keyword matches — powered by embeddings. 'car' and 'automobile' are semantically similar.
  </Card>
  <Card title="Function Calling" icon="seti:function">
    Letting an LLM call external functions (APIs, code, databases). Bridges the gap between AI and real-world actions.
  </Card>
  <Card title="Structured Output" icon="seti:json">
    Forcing an LLM to output JSON, YAML or specific formats instead of free text. Essential for programmatic use.
  </Card>
  <Card title="Agentic AI" icon="bot">
    AI systems that autonomously take multiple steps (research, write, code, call APIs) to solve complex goals without human intervention.
  </Card>
  <Card title="Inference" icon="rocket">
    Running a trained model to generate outputs. Much cheaper and faster than training. This is what you do when you use ChatGPT.
  </Card>
  <Card title="API" icon="seti:api">
    Application Programming Interface — lets software talk to software. Send prompts to OpenAI/Anthropic and get responses.
  </Card>
</CardGrid>

## 🔴 Advanced Level

For AI engineers and researchers.

<CardGrid>
  <Card title="Parameters" icon="seti:settings">
    Learnable weights inside a neural network. GPT-4: ~1.8T parameters. Phi-4: 14B. More ≠ smarter — efficiency matters.
  </Card>
  <Card title="RLHF (Reinforcement Learning from Human Feedback)" icon="seti:training">
    The training technique used to align LLMs with human preferences. Humans rank outputs, and the model learns to generate preferred responses.
  </Card>
  <Card title="Constitutional AI" icon="scale">
    Anthropic's technique using AI-generated feedback (instead of humans) to train models to be helpful, harmless and honest at scale.
  </Card>
  <Card title="Quantization" icon="compress">
    Reducing model precision (32-bit → 8-bit → 4-bit) to shrink file size and speed up inference on consumer hardware without much quality loss.
  </Card>
  <Card title="LoRA (Low-Rank Adaptation)" icon="seti:git">
    Efficient fine-tuning that trains only small adapter layers, not the entire model. 100x faster and cheaper fine-tuning.
  </Card>
  <Card title="Knowledge Distillation" icon="droplet">
    Training a smaller 'student' model to mimic a larger 'teacher' model. Result: smaller, faster model with 85-95% of teacher performance.
  </Card>
  <Card title="Pruning" icon="scissors">
    Removing unimportant weights from a model to reduce size and latency without significant performance loss.
  </Card>
  <Card title="Mixture of Experts (MoE)" icon="network">
    Architecture where different 'expert' networks handle different types of inputs. Allows scale without activating all parameters. Used in Grok, Gemini.
  </Card>
  <Card title="Speculative Decoding" icon="forward">
    Inference optimization where a smaller/faster model predicts the next few tokens, then a larger model validates them in parallel. 2-3x speedup.
  </Card>
  <Card title="Prompt Caching" icon="cache">
    Storing frequently-used prompts/documents in a cache to avoid reprocessing the same tokens. Major cost/latency improvement for long-context tasks.
  </Card>
  <Card title="Open Weights" icon="open-book">
    Model weights publicly released. Anyone can download, run and fine-tune them (Llama 4, Mistral, Qwen, DeepSeek).
  </Card>
  <Card title="Synthetic Data" icon="sparkles">
    Artificially generated training data created by AI models. Increasingly used to improve model quality when human-labeled data is scarce.
  </Card>
  <Card title="MCP (Model Context Protocol)" icon="plug">
    Anthropic's open standard for connecting AI models to external data sources and tools. Enables safer, more controlled integrations.
  </Card>
  <Card title="Attention Mechanism" icon="eye">
    The core of Transformers — allows the model to 'focus' on relevant parts of the input. Computes weighted importance scores between tokens.
  </Card>
  <Card title="Positional Encoding" icon="location">
    Technique for telling a Transformer the order of tokens in a sequence. Without it, 'cat dog' = 'dog cat' to the model.
  </Card>
  <Card title="Backpropagation" icon="wave">
    The algorithm that trains neural networks by calculating gradients and updating weights. 1986 breakthrough that enabled deep learning.
  </Card>
  <Card title="CLI (Command Line Interface)" icon="terminal">
    Text-based way to interact with software by typing commands. Claude Code, Aider, Cursor use CLIs for agentic coding.
  </Card>
</CardGrid>

## ✨ May 2026 Highlights

Terms and concepts that became important or changed this year.

<CardGrid>
  <Card title="Reasoning Models" icon="brain">
    **NEW:** Models trained to 'think' before answering (OpenAI o1, DeepSeek r1). Spend compute upfront to think, trade speed for accuracy on hard problems.
  </Card>
  <Card title="Instant Models" icon="lightning">
    **NEW:** Ultra-fast, cheap variants for simple tasks. GPT-5.5 Instant: $0.05/1M input tokens. DeepSeek Flash: $0.14/1M. Same quality as full models for most tasks.
  </Card>
  <Card title="Real-Time AI" icon="clock">
    **NEW:** AI that processes live video/audio streams without buffering. Critical for autonomous vehicles, live translation, interactive apps.
  </Card>
  <Card title="Grok 3" icon="zap">
    **NEW:** xAI's model with real-time X/Twitter data integration. Only model that 'knows' what's trending right now.
  </Card>
  <Card title="Claude 4.7" icon="book">
    **UPDATED:** Anthropic's flagship — 400K context window (8x larger), better reasoning, improved coding and function calling.
  </Card>
  <Card title="GPT-5.5" icon="sparkles">
    **UPDATED:** OpenAI's new generation — faster, cheaper, better at code. Plus Instant variant for cost-sensitive tasks.
  </Card>
  <Card title="Gemini 3.1 Pro" icon="google">
    **UPDATED:** Google's frontier model — 1M context window. Can ingest entire codebases, research databases, books in one prompt.
  </Card>
  <Card title="DeepSeek V4" icon="rocket">
    **UPDATED:** Chinese model matching GPT-4o quality at 1/10th the cost ($0.14-0.28 per 1M tokens). Disrupted the market.

  <Card title="Agentic Coding" icon="code">
    **TREND:** Cursor (78% SWE-bench), Windsurf (75%), Claude Code, Aider. Autonomous refactoring, PR generation, bug fixing now industry standard.
  </Card>
  <Card title="Cost Optimization" icon="dollar">
    **TREND:** Smart routing (cheap models for easy tasks, expensive for hard), prompt caching, batch processing. Cutting API costs 50-80%.
  </Card>
  <Card title="Privacy-First AI" icon="lock">
    **TREND:** Local inference with Ollama/vLLM becoming viable. Llama 4, Qwen 3.5 now match proprietary quality for private use cases.
  </Card>
</CardGrid>

## Common Misconceptions (Debunked)

<CardGrid>
  <Card title="'AI will have AGI by 2026'" icon="calendar">
    No. We have narrow AI (good at specific tasks). AGI (general intelligence) is still years away. Current models can't reason consistently or learn new tasks in context.
  </Card>
  <Card title="'More parameters = smarter'" icon="scale">
    False. Phi-4 (14B) beats many 70B models. Efficiency, data quality, training techniques matter more than raw parameter count.
  </Card>
  <Card title="'LLMs are conscious / sentient'" icon="heart">
    No. They're statistical pattern-matching machines. No feelings, awareness or intentionality. They optimize for text probability, nothing more.
  </Card>
  <Card title="'AI knows everything recent'" icon="newspaper">
    False. Training cutoff dates exist. Claude 4.7 trained May 2025. Without web search tools, it doesn't know about recent events.
  </Card>
  <Card title="'Open Source = Free'" icon="warning">
    Not always. Some have restrictive commercial licenses. Always check before using commercially.
  </Card>
  <Card title="'AI will take my job'" icon="briefcase">
    AI automates tasks, not jobs. People who learn to work WITH AI thrive. People who ignore it are most at risk.
  </Card>
</CardGrid>
