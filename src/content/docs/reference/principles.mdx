# Principles for AI

Seven guiding principles for using AI effectively and responsibly.

## Coming Soon

This reference section has been reorganized from the main principles page.

**Core principles:**
1. Understand the tool's limitations
2. Verify outputs, don't blindly trust
3. Consider bias and fairness
4. Respect privacy and data
5. Use for augmentation, not replacement
6. Stay informed about evolving capabilities
7. Think critically about impact

Each principle includes explanations and practical examples.
