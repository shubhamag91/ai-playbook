# Open Source Models

Open-weight models you can run, fine-tune and build on — often rivalling closed frontier models.

> **Open Source vs Open Weights:** True open-source includes training code and data. "Open weights" (Llama, Mistral) releases model weights but not always training data. Both are valuable — check licenses before commercial use.

## Example Architecture: AI Agent with WhatsApp Control

A practical example of how to connect messaging, AI models, and automation into a working system. This pattern is commonly used for personal AI assistants, automated customer support, and agentic workflows.

### Messaging Interface
**WhatsApp / Discord / Telegram** — User-facing chat interface. Users send messages, AI responds — familiar, accessible, no app install needed.

Alternatives:
- **WhatsApp** — Most accessible globally
- **Discord** — Best for communities, bots, voice
- **Telegram** — Better bot API, privacy

### Automation Layer
**n8n / Zapier** — Connects the messaging platform to your AI. Receives messages, triggers workflows, sends responses.

### AI Layer
**Ollama (local) or OpenAI / Anthropic API** — The brain. Processes user requests, generates responses.

### Example: Personal AI WhatsApp Assistant

1. User sends a message on WhatsApp
2. n8n receives it via Twilio or WhatsApp Business API
3. n8n sends the message to Ollama or OpenAI API
4. Response comes back and n8n sends it to WhatsApp

## Getting Started Locally

![Visual walkthrough — running Ollama locally](/ollama_local_setup.png)

1. **Install Ollama:** `curl -fsSL https://ollama.ai/install.sh | sh`
2. **Pull a model:** `ollama pull llama3.3` or `ollama pull mistral`
3. **Chat in terminal:** `ollama run llama3.3`
4. **Use the API:** Ollama runs a local REST API at `http://localhost:11434` — OpenAI-compatible.
5. **GUI option:** Install LM Studio for a desktop ChatGPT-like interface with model management.
