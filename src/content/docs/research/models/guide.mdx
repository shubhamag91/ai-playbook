Open-weight models you can run, fine-tune and build on — often rivalling closed frontier models.

> **Open Source vs Open Weights:** True open-source includes training code and data. "Open weights" (Llama, Mistral) releases model weights but not always training data. Both are valuable — check licenses before commercial use.

## Example Architecture: Private RAG Chatbot

A practical example combining an open-weight model, a vector database, and a local interface. This pattern works for document Q&A, support bots, and knowledge retrieval — all running on your own hardware.

### Architecture

```
User Question → Ollama (Llama 4) ← RAG pipeline (Chroma + embeddings)
                          ↓
                 Generated Answer → User
```

### Implementation

1. **Load documents** into Chroma vector DB (PDFs, markdown, code)
2. **Convert question** to embedding using a local embedding model
3. **Retrieve** top 3-5 relevant document chunks from Chroma
4. **Send question + chunks** to Llama 4 (via Ollama API)
5. **Return answer** to user

### Why This Matters

No data leaves your machine. No API costs. Full control over the model. This same pattern scales from a laptop to a production server by swapping Ollama for vLLM and Chroma for Qdrant.

### Alternatives

| Component | Starter | Production |
|---|---|---|
| LLM | Ollama + Llama 4 | vLLM + Llama 4 70B |
| Vector DB | Chroma (embedded) | Qdrant or Weaviate |
| Embeddings | Ollama built-in | BGE or Instructor |
| Interface | CLI / Streamlit | Custom web app |

## Getting Started Locally

![Visual walkthrough — running Ollama locally](/ollama_local_setup.png)

1. **Install Ollama:** `curl -fsSL https://ollama.ai/install.sh | sh`
2. **Pull a model:** `ollama pull llama4` or `ollama pull deepseek-r1`
3. **Chat in terminal:** `ollama run llama4`
4. **Use the API:** Ollama runs a local REST API at `http://localhost:11434` — OpenAI-compatible.
5. **GUI option:** Install LM Studio for a desktop ChatGPT-like interface with model management.
