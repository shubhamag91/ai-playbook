## January 2026

### DeepSeek V3 Release (Jan 8)
- **Reasoning capability** matching GPT-4o on most benchmarks
- **Open weights** under MIT license
- **Cost:** $0.27/$1.10 per 1M tokens (API)
- **Impact:** First open-weight reasoning model at scale

### Llama 3.2 (Jan 15)
- Incremental improvements over 3.1
- Better instruction-following
- Faster inference

---

## February 2026

### Claude 3.5 Sonnet Update (Feb 3)
- **Improved coding** (now 95% HumanEval accuracy)
- **Better structured output** handling
- **Prompt caching** (cheaper for repeated context)
- **Cost:** $3/$15 per 1M tokens

### Mistral Large 2 (Feb 10)
- **Better multilingual** support (20+ languages)
- **Context:** 128K tokens
- **Cost:** $2/$6 per 1M tokens

### Gemini 2.0 Pro (Feb 20)
- **Multimodal reasoning**
- **Video understanding** (12 fps streaming)
- **1M context window**
- **Cost:** $10/$30 per 1M tokens (free tier: 150M/day)

## May 2026 (Current)

- **Agents enabled by default**

- **Cost:** $8/$24 per 1M tokens

### GPT-5.5 Release (May 8)
- Multimodal reasoning
- **1000 tokens/sec** streaming
- **Cost:** $0.10/$0.30 per 1M tokens
- Status: Available on API + ChatGPT Plus

### Gemini 3.0 Official Launch (May 15)
- **2M context window**
- Native reasoning mode
- Integrated with Workspace
- **Cost:** $10/$30 per 1M tokens
- **Free tier:** 150M tokens/day

## For Builders

**Pick a model based on:**
1. **What you're building** (chat? code? multimodal?)
2. **Your constraints** (speed? cost? privacy?)
3. **Your fallback** (have a 2nd choice if primary is down)

**2026 advantage:** Redundancy is cheap. Use multiple models. If one fails or gets slow, swap to another.
