## What's An LLM?

An **LLM (Large Language Model)** is software that predicts the next word by pattern matching. ChatGPT, Claude, Gemini  -  they all work this way. That's the whole concept.

**Key facts:**
- Trained on billions of text examples (books, web, code)
- Better at predicting = smarter responses
- Not magic. Not conscious. Just very advanced autocomplete
- Can write, code, analyze, summarize, explain  -  anything involving language

**What they can't do:**
- Access the internet (unless the app integrates it)
- Do reliable math
- Know anything after their training date
- Guarantee true information

## Common Questions

**How do I start using AI?**
Pick a free tool: Claude (chatbot), ChatGPT (web search), or Gemini (visual content). Try one for 15 minutes.

**What's the best model?**
Claude Sonnet for most tasks. Opus for reasoning. Haiku for speed. See [Models Guide](/decide/models/guide/).

**How much does it cost?**
Free to start (all major tools have free tiers). Paid plans: $10–20/month. See [Cost Calculator](/decide/cost-calculator/).

**Is it going to replace me?**
No. It's a tool. Like email, spreadsheets, or search engines. It augments what you do, not replaces you.
