## How it works

The mind map is generated from a plain Markdown outline. The source lives at `public/mindmaps/ai-landscape.md`.

To update it, edit that file, then regenerate the HTML with:

    npx markmap-cli public/mindmaps/ai-landscape.md -o public/mindmaps/ai-landscape.html --no-open

Commit both files. The iframe above will pick up the new version.

:::tip[Tools]
Install the Markmap VS Code extension for live preview while you edit the outline.
:::
