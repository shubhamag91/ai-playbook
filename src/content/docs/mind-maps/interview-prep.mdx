## How it works

The mind map is generated from a plain Markdown outline. The source lives at `public/mindmaps/interview-prep.md`.

To update it, edit that file, then regenerate the HTML with:

    npx markmap-cli public/mindmaps/interview-prep.md -o public/mindmaps/interview-prep.html --no-open

Commit both files. The iframe above will pick up the new version.

:::tip[Tools]
Install the Markmap VS Code extension for live preview while you edit the outline.
:::
