This is a placeholder for the Intro to LLMs slide deck. The deck needs to be exported from Slidev and placed in `public/decks/intro-to-llms/`.

## Topics covered

- What is an LLM?
- How do LLMs work?
- Tokens and context windows
- Prompt engineering basics
- Common use cases

## To create the deck

1. Install Slidev: `npm init slidev`
2. Edit `decks/intro-to-llms/slides.md`
3. Export to HTML: `slidev export --format html`
4. Copy output to `public/decks/intro-to-llms/`

Commit `public/decks/intro-to-llms/`, push, done — the iframe above will load it.

:::tip
Prefer Reveal.js? Same idea: export to `public/decks/<name>/` and point the iframe at it. Markdown source stays the source of truth.
:::
