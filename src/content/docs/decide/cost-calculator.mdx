### Cost Breakdown Formula

```
Daily cost = (requests × input_tokens × input_price/1M) + (requests × output_tokens × output_price/1M)
Monthly cost = Daily cost × 30
```

  const requests = parseInt(document.getElementById('reqCount').textContent.replace(/,/g, '')) || 100;

    sonnet: { in: 3, out: 15 },
    haiku: { in: 0.80, out: 4 },

    gpt: { in: 2, out: 8 },
    gemini: { in: 2, out: 12 },
    deepseek: { in: 0.14, out: 0.28 }
  };
  
  const calcCost = (inPrice, outPrice) => {
    const dailyCost = (requests * inTokens * inPrice / 1000000) + (requests * outTokens * outPrice / 1000000);
    return (dailyCost * 30).toFixed(2);
  };
  
  document.getElementById('costSonnet').textContent = '$' + calcCost(pricing.sonnet.in, pricing.sonnet.out);
  document.getElementById('costHaiku').textContent = '$' + calcCost(pricing.haiku.in, pricing.haiku.out);

## Cost Optimization Tips

### 1. Use Cheaper Models When Possible
- Haiku for simple tasks (5x cheaper than Sonnet)
- DeepSeek for massive volume (100x cheaper)
- Only use Opus when Sonnet fails

### 2. Reduce Input Tokens
- Summarize before sending to API
- Use fewer examples in prompts
- Cache repeated context

### 3. Use Caching
- First request: 100% cost
- Subsequent requests: 10% cost
- Saves 90% on repeated analysis

### 4. Batch Process
- Instead of 100 individual requests: 1 batch of 100
- Can save significantly depending on API

### 5. Route Based on Complexity
- Use Haiku to decide if task needs Sonnet
- ~80% of requests → Haiku
- ~20% of requests → Sonnet
- Result: 60-70% cost reduction

## When Costs Get High

| Monthly Cost | Action |
|--------------|--------|
| Under $10 | Ignore, just use what you need |
| $10-100 | Monitor, consider optimization |
| $100-1000 | Implement routing/caching |
| Over $1000 | Evaluate fine-tuning or self-hosting |

## ROI Calculation

**Question:** Is the cost justified?

**Calculation:**
```
Time saved per request × Value of your time × Requests/month
  vs
Cost per month
```

**Example:** Chatbot saves 5 minutes per conversation
- 5 min × $1/min = $5 value
- 100 conversations/month = $500 value
- Cost: $2.10/month
- **ROI: 23,700%** ✅
