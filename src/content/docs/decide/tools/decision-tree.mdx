## Conversational AI

```
What do you need?
│
├─ General chat, web search, creative writing
│   └─ ChatGPT (fast, all-purpose)
│
├─ Long-form writing, analysis, nuance
│   └─ Claude (best prose quality)
│
├─ Very long documents, research
│   └─ Gemini (1M context, Workspace)
│
├─ Research with cited sources
│   └─ Perplexity (real-time, citations)
│
├─ Analyze your own documents/papers
│   └─ NotebookLM (free, audio summaries)
│
├─ Multi-language research, agentic browsing
│   └─ Kimi (long context, web browsing)
│
├─ Run models locally, fully private
│   └─ Ollama (free, open-source)
│
└─ Windows/Office ecosystem
    └─ Microsoft Copilot (Edge, Bing, Office)
```

## Code & Build

```
What are you building?
│
├─ Daily coding in an IDE
│   ├─ Large codebases, multi-file refactors → Cursor
│   ├─ Terminal-first, automation, CI → Claude Code
│   └─ Simple inline, team-friendly → GitHub Copilot
│
├─ Building apps without coding
│   ├─ Full-stack app from description → Lovable
│   └─ React components from description → Vercel v0
│
├─ Browser-based coding
│   └─ Bolt.new or Replit
│
└─ Agentic / multi-step workflows
    └─ Windsurf (Codeium's agentic IDE)
```

## Infrastructure

```
What infrastructure do you need?
│
├─ GPU compute
│   ├─ NVIDIA H100/B200  -  default for training/inference
│   ├─ AMD MI300X  -  NVIDIA alternative
│   ├─ Google TPU  -  custom ASIC for Google Cloud
│   └─ Groq LPU  -  fastest LLM inference chip
│
├─ Vector databases (for RAG)
│   ├─ Managed, serverless → Pinecone
│   ├─ Self-hosted, GraphQL → Weaviate
│   ├─ Simple, local-first → Chroma
│   ├─ Fast, Rust-native → Qdrant
│   └─ Already on Postgres → pgvector
│
└─ Model APIs
    ├─ Open models via API → Replicate / Together AI
    └─ 100+ models, single API → OpenRouter
```
