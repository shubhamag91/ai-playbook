## Conversational AI

| Tool | Best For | Cost | Key Limitation |
|---|---|---|---|
| ChatGPT | General tasks, web search, creative writing | Freemium | Shorter context |
| Claude | Long-form writing, nuanced analysis | Freemium | Slower responses |
| Gemini | Very long documents (1M context), Google ecosystem | Freemium | Weaker at coding |
| Perplexity | Research with cited real-time sources | Freemium | Not for long-form writing |
| NotebookLM | Document/paper analysis, audio summaries | Free | Google-only ecosystem |
| Kimi | Multi-language research, agentic browsing | Freemium | Smaller user base |
| Ollama | Local private models, no API needed | Free | Requires GPU/RAM |
| Microsoft Copilot | Windows/Office integration, Bing search | Freemium | Less capable standalone |
