## How Pages Appear in the Sidebar

### Manual Entries

Root-level pages and most top-level items use explicit `{ label, slug }` entries:

```js
{ label: 'Cost Calculator', slug: 'decide/cost-calculator' },
```

### Autogenerated Folders

Subdirectories use `autogenerate` to auto-populate from files:

```js
{ label: 'Cheatsheets', collapsed: true, autogenerate: { directory: 'reference/cheatsheets' } },
```

Files added to autogenerated directories **automatically appear** without sidebar config changes.

### Current Autogenerated Directories

| Directory | Sidebar position | Collapsed |
|---|---|---|
| `reference/cheatsheets` | Reference section | Yes |
| `resources/case-studies` | Resources section | No |
| `resources/templates` | Resources section | No |

## Nested Groups

### Deep Dives (3 subgroups)

```js
{
  label: 'Deep Dives',
  items: [
    {
      label: 'Core Architecture',
      items: [
        { label: 'How LLMs Work', slug: 'deep-dive/how-llms-work' },
        // ...
      ],
    },
    // Techniques & Methods, Production & Operations
  ],
}
```

Note: Adding a `collapsed: false` to subgroup labels ensures they're not collapsible (always expanded).

## Badges

Pages can show colored badges:

```yaml
# In file frontmatter
sidebar:
  badge:
    text: New
    variant: tip  # tip, note, danger, caution, success
```

Only use sparsely — reserved for genuinely new or updated content.

## Adding a New Page

### In an autogenerated directory (e.g., cheatsheets):
1. Create the file: `src/content/docs/reference/cheatsheets/my-topic.md`
2. Add frontmatter with `sidebar.order` for ordering
3. Done — appears automatically

### Outside autogenerated directories:
1. Create the file
2. Add frontmatter with `sidebar.order`
3. Manually add a `{ label, slug }` entry in `astro.config.mjs`

## URL Routing (Important)

Starlight routes by folder/filename:

| File path | URL |
|---|---|
| `src/content/docs/tools.md` | `/tools/` |
| `src/content/docs/decide/models/guide.mdx` | `/decide/models/guide/` |

The `slug` in sidebar config omits `src/content/docs/` and the file extension.

---

## Order Convention

`sidebar.order` values are per-section, not global. Lower = higher in sidebar:

```yaml
sidebar:
  order: 2
```

Within autogenerated directories, files are sorted by `order` first, then alphabetically.

---

## Redirects for Moved Pages

When a page changes URL, update `public/_redirects`:

```
/old-path /new-path 301
```

This is a Cloudflare-native redirect — it only works in production, not local dev.
